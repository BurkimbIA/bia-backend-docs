WarmupRequest

Ask for a serverless worker to be booted ahead of the real request. Costs no quota: it starts a GPU, it does not do the user's work.
service
​string · enum · required

Which endpoint to boot. Send the one the opened tab will use.

Enum values:
transcription
tts
translation
Example: transcription

WarmupResponse

service
​string · required
status
​string

'accepted' when the boot was queued, 'quota_exhausted' when the caller has nothing left to spend so no GPU was started. returns immediately. Whether it actually submitted a job or was debounced is a server-side detail, visible in the logs.

Default: accepted
